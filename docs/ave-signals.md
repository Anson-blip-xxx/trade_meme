# Ave 信号接入与交叉观察

2026-10-16 对 [Ave 信号页](https://ave.ai/smart) 的正常网页请求和实时消息进行只读验证。本模块使用网站当前实际协议，未发现可据此承诺兼容性的公开版本协议；接口变化会显示异常，不伪造成功。

## 采集与账户

`AVE_SCANNER_ENABLED=true` 启用独立采集器。`wss://yiyulu.com/ws` 订阅 `signalsv2_public_monitor`，按配置选择 BSC、Solana、Robinhood。已实测公开连接收到新信号；界面将“公开流连接”和“账号验证”分别显示，不把公开连接算成登录，也不假定匿名 Ave 与 DeBot 一样延迟十分钟。心跳、指数退避重连和 60 秒 HTTP 补数独立于页面刷新。

邮箱验证码通过 Ave 正常登录页使用。服务器只保留 `AVE_SESSION_PATH` 中的最小会话字段：`version`、固定邮箱、`savedAt`、access/refresh token、网站 X-Auth。目录 0700，文件 0600，不进入 Git。登录态通过当前账号钱包关联的用户信息核验邮箱，不能仅凭 JWT 内容宣称认证成功。读取信号不获取助记词、私钥，也不请求交易或签名。

会话客户端按需刷新 access token，临近到期轮换 refresh token；每次 HTTP 补数执行身份/时效检查。401 降级并在后续请求尝试恢复。refresh token 被撤销、过期或网站要求重新登录时会标明需要登录；不能将 Gmail 连接器宣称为服务器自带的后台邮件 API。已授权的邮箱可在后续维护会话中再次完成验证码登录，无需重复索取账户授权。全新登录不会被伪装成普通 token 刷新。

HTTP 补数使用网站的 `/v2api/signals/v2/public/multi_chain/list`。按实际网页协议携带 X-Auth，并从已核验账号的钱包列表选择首链地址作为 wallet_address；该公开路由不发送 Bearer。地址只保存在内存，不允许调用者指定别人的钱包。账号状态核验、刷新与信号读取限定固定主机和路径，禁止任意 URL、重定向、交易请求；网络总超时 8 秒，采集外层 10 秒。接口返回缺失、限流或拒绝时保留明确缺口。

## 通知、研究和交易边界

通知以 **链＋完整 CA＋标签＋signal_time** 去重，供应商可变行 ID、价格、累计通知次数不产生新事件。保留首次接收时间，重启和重复投递不刷新信号年龄。`first_signal_time` 与当前这次 `signal_time` 分开保存，供应商历史最高涨幅不作为本地当时可见特征。

每条新通知先入库并进入 Meme 持续观察，再排队完整合约/市场/钱包研究。同币待处理通知合并为最新一次，完整分析同币至少间隔 60 秒，Ave 只有一个在途研究任务，并让出既有 GMGN 请求冷却和研究容量。超过 120 秒不再作为新鲜通知分析；保留历史原因，不用接收时间替换供应商时间。队列状态与安全结论分开展示。

Ave 是新增研究来源，订单控制器对 `source=ave` 返回 `ENTRY_SOURCE_RESEARCH_ONLY`，在余额查询、报价、签名和订单创建前拒绝；即使全局后来切到 live，该来源仍不能直接开单。合约安全、是否达到原候选条件与这个研究限制分别记录。

## 交叉判断与钱包

`data/source-corroboration.sqlite` 独立记录实际供应商观察，不把复评、画像生成的本地 GMGN 候选重新算成供应商提醒。GMGN 原始页在研究名额筛选前采集；来源证据不受每轮完整研究数限制。同链同 CA 在最近 5 分钟同时有至少两个新鲜来源，标为“多来源”；迟到、过期、未来时间、身份/时间冲突分别展示。Meme 历史快照保存当时交叉结果，后来通知不能修改旧快照。旧数据无当时记录的字段保持缺失。

多平台可能引用同一笔交易，来源数量不增加评分，不等于独立资金数量。交叉账本能够保留校验格式后的交易引用并标示共享交易；Ave 当前信号 actions 没有交易哈希，因此不能证明独立链上买卖或钱包归属。真实收到的 Ave 完整钱包地址先在长期钱包库保存为独立的“供应商待核验线索”，风控拒绝、分析超时和未分配研究额度不会使地址只剩短期通知记录。线索不增加交易数、持币数、利润或关联分，不将平台别名写成已验证身份。每次最多提名 3 个进入既有 GMGN 钱包研究，实际选中数受统一请求预算限制；真实交易核验、地址归因与后续画像沿用现有链路。别名和“KOL/聪明钱”标签只保留为供应商描述。

Ave 通知库保留 30 天、最多 10,000 条、上限 64 MiB。来源账本保留 30 天、最多 100,000 条，默认 128 MiB；容量不足明确报警，不通过重置首次时间掩盖缺口。长期钱包研究仍在原钱包数据库中，不受这两类短期通知清理影响。

## 页面与接口

“信号来源”栏目显示 Ave 连接、认证、延迟、队列及分页记录；“Meme 动态”显示当前交叉来源，详情保存历史交叉状态并提供来源通知分页。默认列表 20 条，切换栏目才加载，不给首页增加完整信号列表请求。

- `GET /dashboard/api/ave/signals?limit=20&offset=0&chain=bsc&asOf=...`
- `GET /dashboard/api/sources/:chain/:address/events?limit=20&offset=0&asOf=...`

以上接口沿用工作台认证且只读；不返回会话 token。配置完整示例见 `.env.example`。单元测试覆盖重复/错链/时间异常/容量/取消关闭、身份验证和刷新、分页与历史冻结，以及 Ave 不会触发订单。
